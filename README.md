# Notícias Reais

Notícias do dia com todos os lados, no estilo Ground News: quem cobriu (esquerda, centro, direita, imprensa estrangeira), como governo e oposição enquadram, pontos cegos e um resumo que separa fato, inferência e alegação em disputa.

- **App:** https://hfneto.github.io/noticiasreais/ (PWA: no iPhone, abra no Safari → Compartilhar → Adicionar à Tela de Início)
- **Conteúdo:** gerado por Routines do Claude Code seguindo o [CLAUDE.md](CLAUDE.md)
- **Vieses dos veículos:** [data/fontes.json](data/fontes.json), editável
- **Pedir uma busca:** abra uma issue com título `busca: <assunto>` (o app faz isso por você)
